项目仓库

怎么用

  1. 在下面按时间顺序补录注射和症状，点「添加」。
  2. 点「下载 JSON」，把文件发到手机（微信文件传输/数据线都行）。
  3. 手机上打开 BioClock → 设置 → 导入数据 → 选择这个文件。

数据只保存在当前浏览器（localStorage），不会上传到任何服务器。换浏览器或清缓存会丢失，记得先下载备份。
