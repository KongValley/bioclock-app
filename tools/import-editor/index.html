BioClock 导入编辑器

补录注射、口服打卡与症状，导出成 App 可以导入的文件。

项目仓库

怎么用

  1. 先选病种、补上目录里没有的药，再按时间顺序补录注射、口服打卡和症状，点「添加」；也可以下载 Excel 模板在 Excel 里填。
  2. 点「下载 Excel」或「下载 JSON」：自定义药物会一起打包进文件，再把文件发到手机（微信文件传输/数据线都行）。
  3. 手机上打开 BioClock → 设置 → 导入数据 → 选择这个文件。

数据只保存在当前浏览器（localStorage），不会上传到任何服务器。换浏览器或清缓存会丢失，记得先下载备份。
