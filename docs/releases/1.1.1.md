# BioClock 1.1.1

修复提醒、历史记录、数据导入及导出问题，保留原有本地数据。Android 更新时可覆盖安装。

- 提醒：已用、跳过、漏用的计划不再重复推送；修复口服免打扰顺延、14 天覆盖和后台回前台续排；数据读取或通知渠道创建失败时保留已有提醒。
- Android 通知：从备份恢复后也会建立用药提醒渠道，避免依赖默认渠道。
- 历史记录：停用治疗方案后仍可查看和编辑原有注射、口服记录。
- 导入：药物、用药线、打卡、症状、标签、停用状态和疗效事件统一事务回滚；支持停用前历史补录、药名别名及疗效事件去重；预览数量与实际写入一致。
- 导出：CSV、PDF 增加已用 / 跳过 / 漏用状态；修复 PDF 临时文件读取权限，明确依从性统计使用全部历史。
- 同步此前未合入主分支的排程、换机恢复、药物目录与数据校验修复，更新开发文档及用户手册。

自动化验证：TypeScript 检查通过，18 个测试文件、183 个用例通过，Android Metro / Hermes 构建通过。

独立 APK 已在 Android 15 MuMu 验证通知准时投递、注射通知冷启动、口服通知运行中跳转及保存打卡。此前 Expo Go 的启动器崩溃没有在独立安装包中复现。详见 [独立 APK 验收记录](../qa-2026-11-03.md)。

记录、提醒和导入导出均在本机处理。所有方案参数由用户按医嘱填写；症状和趋势仅用于自我观察，不构成因果判断。
