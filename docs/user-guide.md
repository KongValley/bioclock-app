# BioClock 用户手册

> 适用版本：1.1.0 ｜ 更新：2026-11

BioClock 是一个帮助你记录生物制剂注射、口服用药和症状，并按时提醒下次用药的个人工具。

它只做记录、算术和提醒，**不提供诊断、处方、剂量调整或换药建议**。所有用药方案、剂量和间隔都应由你和医生共同确定，并以医生处方和药品说明书为准。

## 1. 第一次使用

首次打开 App 会进入四步引导。

### 1.1 选择病种

- 可以同时选择多个病种（例如克罗恩病 + 强直性脊柱炎）。
- 可以按病名或别名搜索。
- 病种会影响下一步展示的药物和方案模板。

### 1.2 选择药物

- 列表按你选择的病种展示内置药物，标注「常用」的是一线选择。
- 如果药不在列表里，选择「自定义药物」，填写药名、通用名、给药途径和默认剂量。
- 内置目录只收录皮下注射 / 静脉输注生物制剂；口服药请用自定义药物并选择「口服」。

### 1.3 确认用药方案

- 填写方案名称。
- 按医嘱设置阶段：负荷剂量 / 维持剂量、间隔天数、重复次数、剂量和单位。
- 没有负荷期时，可以一键只保留维持阶段。
- 如果记得上一次注射时间，可以填进去；下一次会从那个时间起算。
- 页面会预览前 5 针的时间和剂量，仅用于核对，**以医生处方为准**。

> 首次引导只创建一个药物和一条用药线。需要联合用药时，完成引导后到「设置 → 编辑治疗方案」里添加。

### 1.4 设置提醒

- 选择提醒时间（默认 09:00）。
- 选择提前几天提醒：3 / 2 / 1 / 0 天。
- 设置免打扰时段（默认 22:00–08:00）。
- 按提示允许通知权限；Android 12+ 还需要允许「精确闹钟」，否则可能不准点。

### 1.5 从旧手机恢复

如果你已经有一份 BioClock 换机备份，可以在引导第一步点「从备份恢复」，选择旧手机导出的 `.json` 文件。恢复成功后会自动进入首页，不需要再手动建方案。

## 2. 首页（今天）

首页围绕「下一次用药」组织：

- **下次注射卡片**：显示还有几天、今天该注射、或已逾期几天。
- **今天要做**：当天到期的注射和口服任务，可以直接完成或跳过。
- **用药计划**：每条用药线显示下一步、时间、剂量和给药方式。
- **已停用**：停用的用药线会保留在这里，可在设置里恢复。
- **推荐注射部位**：根据历史记录推荐轮换位点；腹部注射需距脐 5cm 以上。
- **冷藏药提示**：使用皮下注射主药时，会提示提前 30 分钟取出回温。
- **快捷入口**：右下角「登记注射」，以及「记录症状」按钮。

下拉首页可以重新加载数据。

## 3. 登记注射

1. 从首页「登记注射」、记录页「新增注射」或通知进入。
2. 选择用药线，确认注射时间。
3. 填写剂量和单位；剂量通常会自动带出默认值。
4. 皮下注射选择部位；静脉输注不显示部位选择。
5. 可选填批号和备注。
6. 保存后会立即更新下一次注射时间和提醒。

需要补录历史记录时，使用「保存并继续补录」，可以连续录入多针。

## 4. 口服打卡

1. 从首页「今天要做」、用药计划或记录页「新增口服」进入。
2. 选择口服用药线，确认时间。
3. 选择「完成」或「跳过」：
   - 完成：记录服用时间。
   - 跳过：只记录这次没有服用，不记录服用时间。
4. 可选填剂量和备注。

已保存的口服记录可以在记录页编辑或删除。

## 5. 记录症状

1. 从首页「记录症状」或记录页「新增症状」进入。
2. 选择记录时间。
3. 选择严重程度 1–5。
4. 可选填 NRS 疼痛评分（0–10，0 为无痛）、体温、备注。
5. 选择症状标签；标签可以在同一页面管理，删除标签不会改变历史记录里的文字。
6. 可以关联最近 5 条注射记录，方便复诊时回看时间关系。

症状统计只用于自我观察，**不构成因果判断**。

## 6. 查看、编辑和删除记录

- 记录页分为「注射 / 口服 / 症状」三个分段。
- 列表按月份分组、时间倒序。
- 长按记录或点右侧「更多」按钮，可以编辑或删除。
- 删除注射记录后会重新计算下一次注射时间；删除操作需要确认，且不可恢复。

## 7. 日历

- 按月份查看注射计划，周一为第一列。
- 每天最多显示 3 个状态圆点，更多显示「+N」。
- 点击日期可以查看当天的药名、第几针、负荷 / 维持阶段、剂量和状态。
- 日历只展示注射计划；口服安排请在首页或记录页查看。

## 8. 趋势

- **依从性总览**：按时、提前、延迟、平均偏差、漏用和完成率。
- **各用药线统计**：
  - 注射线：按时 / 提前 / 延迟 / 平均偏差 / 漏打；
  - 口服线：完成 / 漏服 / 完成率。
- **症状与注射时间线**：竖线表示注射，圆点表示症状严重度 1–5，按时间对齐展示。

趋势只用于回看节律，不评判对错，也不构成因果判断。

## 9. 管理治疗方案

### 9.1 编辑方案

设置 →「编辑治疗方案」可以：

- 修改方案名称；
- 添加注射线或口服线；
- 编辑负荷 / 维持阶段、间隔、重复次数、剂量和单位；
- 设置主药和「跟随主药时间」；
- 设置按时窗口（±天）。

一个方案最多一条主药注射线。

### 9.2 停用和恢复

- 设置 →「停用治疗方案」会停用当前方案并取消提醒，历史记录保留。
- 记录页展示全部方案的注射和口服历史；方案停用后仍可查看、编辑原有记录。
- 其他已停用方案会列在「其他治疗方案」里，可以随时重新启用。

### 9.3 从下一针起调整间隔

设置 →「注射间隔」→ 选择用药线和新的间隔：

- 新间隔从下一针开始生效；
- 之前的计划、打卡和趋势不会按新间隔重算；
- 之后补录生效时间之前的历史记录，仍按旧间隔显示。

### 9.4 疗效记录

设置 →「疗效事件」可以记录：

- 疗效下降 / 失效 / 不耐受 / 抗药抗体 / 其他；
- 发生时间和备注；
- 可同时停用这条用药线。

停用后不再生成未来计划，历史保留；需要时可以重新启用。

## 10. 药物、病种和症状标签

- **我的药物**：内置药的名称、通用名、商品名和给药途径由目录维护；可以调整默认剂量。自定义药可以新增、编辑和删除；已被方案使用的药不能删除。
- **病种**：可多选，只影响新建方案时的药物列表，不改变已有方案和记录。
- **症状标签**：管理记录症状时的可选项；删除只影响以后，历史记录里的文字不变。

## 11. 提醒设置

设置 →「提醒」：

- 开启 / 关闭提醒；
- 设置提醒时间；
- 选择提前 3 / 2 / 1 / 0 天；
- 设置免打扰开始 / 结束时间；
- 稍后提醒分钟数可调（0–60 分钟）。

提醒是本地通知，不需要联网。若没有收到提醒，请检查：

1. 系统通知权限；
2. Android 12+ 的「精确闹钟」权限；
3. 是否在免打扰时段；
4. 是否 56 天内打开过 App（通知只滚动预排约 8 周）。

## 12. 导出和备份

设置 →「数据」：

| 功能 | 适合用途 | 内容 |
| --- | --- | --- |
| 换机导出（完整备份） | 换手机 | 方案、用药线、阶段、提醒、打卡、症状、疗效事件、标签和设置 |
| 导出 CSV | 快速查看注射记录 | 全部注射记录，含已用 / 跳过 / 漏用状态，UTF-8 BOM |
| 导出 Excel | 给医生或自己整理 | 注射、症状、药物、口服、用药线五张表 |
| 导出 JSON | 可编辑备份 / 再导入 | 打卡与症状的 v3 备份 |
| 导出 PDF | 复诊 | 姓名（可选）、时间范围、注射记录、症状摘要、依从性统计 |

- PDF 可选 90 / 180 / 365 天。
- 所有导出文件都包含健康信息，分享前请谨慎。
- 导出的文件保存在手机本地，由你自己保管。

## 13. 导入数据

设置 →「导入数据」支持 `.xlsx` / `.xls` / `.json`：

- 导入前会预览将写入的注射、口服和症状数量。
- 重复记录会按时间跳过，同一份文件重复导入不会翻倍。
- 药物按药名、通用名、商品名匹配；找不到会新建自定义药。
- 找不到对应用药线时会自动新建。
- 单个数组最多 2000 条，超出请拆分文件。

## 14. 换手机

1. 旧手机：设置 →「换机导出（完整备份）」→ 保存或分享 JSON。
2. 新手机：安装后进入引导页 →「从备份恢复」→ 选择 JSON。
3. 恢复完成后直接进入首页。

如果新手机已经完成过引导并有激活方案，再导入换机文件时只会合并记录，不会重建旧手机里的方案结构。建议新手机第一次使用时就走「从备份恢复」。

## 15. 隐私与安全

- 数据只保存在本机 SQLite，不需要账号，不会上传。
- App 不发起网络请求，不包含分析或崩溃上报 SDK。
- 卸载 App 会清除本地数据。
- 可以开启应用锁：需要设备已录入指纹 / 面容；解锁时允许系统设备密码回退。应用锁只保护 App 入口，不替代系统锁屏或设备级加密。
- 「清空全部数据」会删除业务数据并回到引导页，内置药物会保留。

## 16. 常见问题

**Q：提醒没有响？**
先检查通知权限、Android 精确闹钟权限和免打扰时段，并定期打开 App。注射滚动预排 56 天，口服预排含当天的 14 天；从后台回到 App 时会自动续排。

**Q：下一次注射时间怎么算？**
默认从上一针的实际注射时间起算，加上当前阶段的间隔；如果方案使用「计划时间」锚点，则从计划时间起算。历史记录和阶段会影响结果。

**Q：改了间隔，历史记录会变吗？**
不会。新间隔从下一针起生效，之前的计划和打卡仍按旧间隔显示。

**Q：跳过和漏用有什么区别？**
「跳过」是你主动记录这次没有用药；「漏用」是按计划时间判断没有完成。两者都会保留在记录里，统计口径不同。

**Q：为什么日历里没有口服安排？**
日历目前只展示注射计划。口服安排请看首页「今天要做」或记录页。

**Q：CSV 里为什么没有症状？**
CSV 只导出注射记录。症状请使用 Excel 或 PDF 导出。

**Q：换手机后方案没有恢复？**
新手机需要在引导页使用「从备份恢复」。如果已经完成引导并有激活方案，导入只会合并记录。

**Q：数据存在哪里？**
只存在本机。没有云备份，请定期使用「换机导出」保存完整备份。

## 17. 医疗声明

BioClock 是个人健康记录工具，不是医疗器械软件。

- 不提供诊断、治疗方案、剂量调整或用药建议。
- 目录中的药名、剂量和给药间隔仅用于减少录入成本，**以医生处方和药品说明书为准**。
- 时间推算和提醒仅供参考，可能因设备时间、系统限制或设置变更而出现偏差。请勿仅依据 App 决定是否用药。
- 症状和趋势仅用于自我观察，不构成因果判断。
- 如有身体不适或用药疑问，请及时咨询专业医疗人员。

## 18. 已知限制

1. 注射预排 56 天、口服预排含当天的 14 天，需要定期打开 App 继续延长。
2. Android 12+ 需要「精确闹钟」权限才能准点提醒。
3. 日历只展示注射计划，不展示口服。
4. 稍后提醒分钟数目前只保存设置，系统通知暂未提供快捷操作。
5. 静脉诱导 + 皮下维持的方案，提醒按药物主途径提示，具体以医生安排为准。
6. PDF 使用系统字体，个别定制 ROM 显示可能略有差异；报告里的依从性统计使用全部历史，注射记录和症状摘要使用所选时间范围。
7. 无自动云备份；换机和备份需要手动导出文件。
